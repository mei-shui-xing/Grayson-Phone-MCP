# Deferred beyond v0.1.0-alpha

The Alpha deliberately defers a cross-project Device Lease Broker, a complete PC/Douyin/phone orchestration layer, release signing and automatic updates, a full automated SBOM platform, broad architecture rewrites, and a requirement that every external/provider/platform integration pass in one run.

Also deferred: audited permission presets that default dangerous tools off, VPN compatibility hardening across every vendor, durable cross-client device leases, and release-grade device-farm coverage. These are follow-up work, not claims made by this candidate.

# 手机 Alpha 最短真机验收

前提：使用测试账号/非敏感页面；先关闭 VPN。锁屏、生物识别、支付、OTP 和权限授权由主人操作。

1. 在 Windows 仓库根目录运行 `scripts\windows\Build-Debug.ps1`，再运行 `scripts\windows\Install-Or-Update.ps1`。
2. 手机端打开应用，主人开启无障碍服务，并只授予本轮需要的权限；启动 MCP 服务。
3. USB 调试时执行 `adb forward tcp:8080 tcp:8080`，在电脑访问 `http://127.0.0.1:8080/health`。确认返回的 `git_commit` 等于报告中的提交、`build_time_utc` 非空且 `tool_count=66`。
4. 连接 MCP，列出工具；在普通设置页或测试 App 依次验证：读取屏幕树/截图、按节点点击、坐标点击、滑动、在非敏感文本框输入测试文字。
5. 从手机常驻通知或 App 内暂停远程触控，确认 AI 的触摸/输入被拒绝；恢复后再确认一次。
6. 熄屏再亮屏、横竖屏各一次，并触发一个普通系统弹窗；确认 AI 不绕过锁屏或权限确认，页面恢复后可继续。
7. AI 任务结束后停止服务或暂停触控，再把手机交还主人。
8. 可选实验：记录关闭 VPN 时的结果后再开启 VPN，分别检查局域网地址、ADB 转发和隧道健康；任何不稳定都按实验性失败记录，不影响“关闭 VPN”的 Alpha 验收。
